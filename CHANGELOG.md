# Changelog

All notable changes to MultiDock1.0 will be documented here.

## [1.0.0] - 2026

### Added
- Graphical ligand-preparation workflow for SDF to PDBQT.
- RDKit and Meeko Python API integration.
- PDBQT validation and preparation logs.
- Batch AutoDock Vina docking.
- User-defined docking box and Vina parameters.
- Automatic extraction and ranking of best Vina scores.
- CSV summaries, docking logs, failed-ligand reports, and parameter recording.
- MultiDock1.0 branding and research-software metadata.
